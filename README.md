# 📝 Blogify – Full Stack Blog Application

Blogify is a full-stack blog application built to learn and practice real-world web development concepts.  
This project covers everything from authentication to CRUD operations, user interaction, and responsive UI.

---

## 🚀 Features

### 🔐 Authentication
- User **Sign Up & Sign In**
- Secure authentication using **JWT**
- Protected routes for authenticated users

### 📰 Blog Management
- Create new blog posts
- View all blogs
- View single blog details
- User-specific blog access

### 💬 Comments System
- Users can **comment on blogs**
- Interactive discussion under each blog post

### 🎨 UI & UX
- Clean and modern UI
- Fully **responsive design**
- Built with reusable React components

---

## 🛠️ Tech Stack

### Frontend
- **React**
- **Tailwind CSS**
- Axios for API calls

### Backend
- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **JWT Authentication**
